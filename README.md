### About me

I enjoy turning repeated friction into simple tools. Most of my work sits around front-end engineering, browser extensions, desktop utilities, web apps, automation scripts, and small product experiments.

I care about interfaces that feel fast, readable, and useful. I like building things that do not need a long explanation: open it, use it, save time, move on.

### What I care about

- Practical front-end engineering with **Vue**, **TypeScript**, **JavaScript**, and modern CSS.
- Desktop and productivity tools with **Tauri**, browser APIs, automation, and lightweight local workflows.
- Developer experience: scripts, small CLIs, data parsing, exporting, testing, and repeatable processes.
- AI-assisted coding, local assistants, self-hosted tools, web scraping, and open-source productivity systems.
- UI details that make tools feel calm: clear structure, quick feedback, and fewer unnecessary dependencies.
