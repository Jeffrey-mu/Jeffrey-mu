### What I build

- Productivity tools for real workflows: shortcut management, clipboard history, screen color picking, Git commit browsing, file/path helpers.
- Browser and web utilities: Chrome extensions, Google tag checkers, AdSense helpers, online tool collections, resource sharing sites.
- Front-end product experiments: Vue/TypeScript apps, UI libraries, H5 games, animation demos, resume/export tools, health trackers.
- Automation scripts and crawlers for repetitive data collection, parsing, exporting, and small operational tasks.

### Current focus

- Making desktop tools with **Tauri**, **Vue 3**, **TypeScript**, and **Tailwind CSS**.
- Building lightweight web apps that are simple to deploy and easy to use.
- Exploring AI-assisted coding, local assistants, self-hosted tools, scraping/automation, and developer productivity.
- Keeping UI details practical: fast interactions, readable structure, and fewer unnecessary dependencies.
